## SST-02 — Brain status pane adapter and Pi Web-style presentation

GitHub：[#17](https://github.com/mtai168/pi-web/issues/17)  
**依賴**：SST-01、通用 SW-05／SW-08／SW-09。

### Scope

- 從 pane 最新 stable Assistant final answer 取得 parser input。
- Streaming 期間保留 last stable status 並另外顯示 running。
- Header 顯示 status／active hands。
- Footer 顯示 milestone／blocker／new dispatches。
- Stale/invalid snapshot 有清楚 fallback。
- 所有視覺沿用 Pi Web tokens 與元件。

### Owner files

```text
components/sausage-session-terminal/BrainStatusSummary.tsx
components/sausage-session-terminal/BrainStatusSummary.test.mjs
components/session-wall/SessionWallPane.tsx (small extension point only)
```

### Acceptance

- [ ] 四種狀態非只靠顏色辨識。
- [ ] 長 blocker 不擠掉 ChatInput。
- [ ] A/B pane 狀態不交叉。
- [ ] Slot 替換立即清除舊 snapshot。
- [ ] Parser 失敗安全回退 runtime state。
