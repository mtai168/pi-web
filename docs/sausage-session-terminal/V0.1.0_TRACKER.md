## SST-02 — Brain status pane adapter and Pi Web-style presentation

**依賴**：SST-01、通用 SW-05／SW-08／SW-09。

### Scope

- 從pane最新stable Assistant final answer取得parser input。
- Streaming期間保留last stable status並另外顯示running。
- Header顯示status／active hands。
- Footer顯示milestone／blocker／new dispatches。
- Stale/invalid snapshot有清楚fallback。
- 所有視覺沿用Pi Web tokens與元件。

### Owner files

```text
components/sausage-session-terminal/BrainStatusSummary.tsx
components/sausage-session-terminal/BrainStatusSummary.test.mjs
components/session-wall/SessionWallPane.tsx (small extension point only)
```

### Acceptance

- [ ] 四種狀態非只靠顏色辨識。
- [ ] 長blocker不擠掉ChatInput。
- [ ] A/B pane狀態不交叉。
- [ ] Slot替換立即清除舊snapshot。
- [ ] Parser失敗安全回退runtime state。
