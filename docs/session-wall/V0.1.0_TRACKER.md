## Milestone 定義

**名稱**：`Session Wall v0.1.0`  
**目標**：交付可日常使用、可操作 4／8／12 個 Pi session、且不破壞 normal mode 的互動式多 Session Wall。

### Milestone release gate

- [ ] SW-01 至 SW-14 全部完成。
- [ ] `npm test` 通過。
- [ ] `node_modules/.bin/tsc --noEmit` 通過。
- [ ] `npm run lint` 通過。
- [ ] `npm run build` 通過。
- [ ] 2×2、2×4、2×6 手動驗收通過。
- [ ] 2×6 60分鐘 soak通過。
- [ ] normal mode regression通過。
